EncodeX for Windows x64

New installation starts with an empty queue and default export settings.
Default output: FolderName_OUTPUT. Paste/select a folder to use Custom Folder.
Clear Queue also resets the export controls to their defaults.
Queues are saved/loaded only when you use Save Queue / Load Queue explicitly.

FFmpeg/FFprobe are detected in Mybin, My Bin, PATH or a previous tools download.
Setup automatically downloads and verifies missing tools before finishing installation; Internet is then required. Existing tools are reused. Retry is offered if preparation fails.
Renderer CPU is available for computers without compatible NVIDIA NVENC hardware.

The installer offers uninstall/upgrade options only after validating a registered
installation and its files. A computer without an installed copy goes through
the normal fresh-install flow. Portable copies are not treated as installed apps.
